# Decisions

Hard-to-reverse decisions get a numbered record in this folder (template: [0001](0001-record-decisions.md)). Easily reversible ones get a line in the register below. Accepted records aren't rewritten: a new record supersedes an old one. Each record's Sources section states the library versions and specification revision it was written against and the date each source was read.
