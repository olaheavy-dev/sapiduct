Three steps, no pipeline to run

Add documents

Drop in PDFs, Word files, Markdown and lecture transcripts. Each one shows its status as it is read and indexed.

Connect an assistant

Copy the server URL and your access token into Claude Desktop or Cursor. Tokens can be rotated or revoked at any time.

Ask, and see the source

Every answer comes back with the passages it used, so you can check it. Try it in the playground before you connect anything.

Studying from a course? Turn on course mode.

The same documents also become a syllabus, session digests, quizzes with spaced repetition and hints for assignments. CourseLens is a module of Sapiduct, so the server keeps working alongside it.
